This month I've written a lot of shaders.

These peculiar images are results of using failed shaders, and the first one was received by conversion of float24 depth buffer data to R8G8B8 format.

My takeaways from experience of writing code for shaders:

1\) If a rendered image doesn't match the expected result, but some noticeable pattern can be observed (pictures 2-5), than it'll most likely be an error in float operations (in my case it was equality comparison).<br />
2\) If a color transition in the final image is not smooth, it'll most likely be a precision issue. In my case, calculations were made with float32 data, but the rendering with float8.
