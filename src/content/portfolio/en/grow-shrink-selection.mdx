In this video, the Grow/Shrink Selection algorithm is demonstrated on a sphere with over 1 million vertices.

The algorithm is implemented using the half-edge data structure from the OpenMesh library and supports:

- Grow/Shrink Selection for vertices, edges, and faces
- Selecting a single connected component in a mesh with multiple disconnected regions
- Edge loop selection

Implemented in **C++14** using [**OpenMesh 9.0**](https://www.graphics.rwth-aachen.de/software/openmesh/).
